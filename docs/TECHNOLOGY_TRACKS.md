# Tecnologias futuras e aplicativo

O usuário quer incluir Django, React, Node.js e outras tecnologias no futuro. São frentes planejadas, sem aulas ou integrações prontas. Cada trilha seguirá o mesmo padrão de fundamentos, comandos explicados, exemplos, exercícios e diagnóstico de falhas de IA.

| Tecnologia | Papel | Base recomendada | Percurso a produzir |
| --- | --- | --- | --- |
| Django | Framework web em Python | Python, funções, objetos, HTTP, SQL e testes | Requisição/resposta, URLs, views, templates, modelos, migrações, formulários, autenticação, testes e implantação |
| React | Biblioteca de interfaces | HTML, CSS, JavaScript, funções, arrays, módulos e eventos | Componentes, props, estado, renderização, formulários, efeitos, acesso a APIs, acessibilidade e testes |
| Node.js | Ambiente de execução de JavaScript fora do navegador | JavaScript, módulos, assincronia, HTTP e testes | Processo, npm, dependências, event loop, arquivos, APIs, erros, validação e testes; frameworks de servidor em uma etapa posterior |

Distinguir biblioteca, framework e ambiente de execução faz parte da explicação inicial. Versões e ferramentas serão escolhidas e conferidas quando a autoria de cada trilha começar. Não criar páginas específicas ou dependências de produção apenas para reservar essas ideias.

## Quando iniciar o aplicativo

O aplicativo móvel ainda não começou. A prioridade atual é consolidar no site o ciclo de leitura, prática, correção e retomada e receber a avaliação posterior do usuário. Não é necessário escrever todas as disciplinas antes de começar o app.

Antes da implementação móvel, definir acesso/autenticação, persistência remota, sincronização entre dispositivos, conflitos e necessidades offline. Depois escolher a tecnologia móvel e produzir um primeiro percurso pequeno consumindo os mesmos contratos e conteúdos. React Native, Expo ou PWA continuam opções em aberto.

A API e os serviços separados da interface facilitam essa evolução. Eles ainda não oferecem sincronização ou funcionamento offline. Um primeiro teste de aceite móvel será estudar uma aula, responder um exercício, retomar o histórico e verificar a consistência entre os clientes conforme a política definida.
